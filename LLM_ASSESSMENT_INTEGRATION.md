## How It Works (Automatically)

### Step 1: Course is Created
```
User creates course with preferences
    ↓
LLM generates course structure
    ↓
Course saved to database
```

### Step 2: Assessments Auto-Generated (NEW!)
```
LLM analyzes course content
    ↓
Generates 4-5 quiz questions per lesson (LLM)
    ↓
Generates 2-3 SAQ questions per module (LLM)
    ↓
Generates 3-4 essay questions for final exam (LLM)
    ↓
All saved to database
```

### Step 3: Students Take Assessments
```
Students take quizzes → Auto-graded
Students submit SAQ → Pending instructor review
Students submit essays → Pending instructor review
```

### Step 4: Instructor Grades (With LLM Help!)
```
Instructor sees pending response
    ↓
Clicks "Get LLM Suggestion" button
    ↓
LLM analyzes response + rubric
    ↓
Returns suggested score + detailed feedback
    ↓
Instructor reviews and accepts/modifies
    ↓
Grade saved with feedback
```

## No Code Changes Needed!

The LLM assessment is **already integrated**. Just follow these 3 steps:

### 1. Verify GROQ_API_KEY

Check your `.env` file has:
```
GROQ_API_KEY=your_key_here
```

If not, add it:
```bash
# Get your key from https://console.groq.com
echo "GROQ_API_KEY=sk_..." >> .env
```

### 2. Import Assessment Blueprint (If Not Done Yet)

In your `run.py`:
```python
from app.routes_assessment import assessment
app.register_blueprint(assessment)
```

### 3. Create Assessments When Saving Course

In your course save function:
```python
from app.services.assessment_service import assessment_service

# After saving course to database:
course_id = db_insert(conn, "INSERT INTO courses ...", (...))

# LLM auto-creates all assessments!
course_data = session.get('generated_course')
modules = course_data.get('modules', [])

for module_idx, module in enumerate(modules):
    assessment_service.create_saq_for_module(course_id, module_idx, module)
    for lesson_idx, lesson in enumerate(module.get('lessons', [])):
        assessment_service.create_quiz_for_lesson(
            course_id, module_idx, lesson_idx, lesson
        )

assessment_service.create_final_assessment(course_id, course_data)
```

**That's it!** The LLM handles the rest.

## Using LLM Grading (Optional)

### For Students Viewing Responses

Create a grading dashboard:

```html
<!-- In admin/grading_dashboard.html -->

<div class="saq-response">
    <h5>Student Response</h5>
    <p>{{ response.answer_text }}</p>
    
    <button class="btn btn-primary" onclick="getSuggestion({{ response.id }})">
        💡 Get AI Grade Suggestion
    </button>
    
    <div id="suggestion-box" style="display:none;">
        <div class="alert alert-info">
            <h6>Suggested Grade: <span id="score"></span>/10</h6>
            <p>Confidence: <span id="conf"></span>%</p>
            <p id="feedback"></p>
            <button onclick="acceptGrade({{ response.id }})">✓ Accept & Save</button>
        </div>
    </div>
</div>

<script>
function getSuggestion(responseId) {
    fetch(`/assessment/llm/grade-saq/${responseId}`, {method: 'POST'})
        .then(r => r.json())
        .then(data => {
            document.getElementById('score').textContent = data.data.score;
            document.getElementById('conf').textContent = 
                (data.data.confidence * 100).toFixed(0);
            document.getElementById('feedback').textContent = data.data.feedback;
            document.getElementById('suggestion-box').style.display = 'block';
        });
}

function acceptGrade(responseId) {
    const score = document.getElementById('score').textContent;
    const feedback = document.getElementById('feedback').textContent;
    
    fetch(`/assessment/llm/apply-grade/${responseId}/saq`, {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify({score, feedback})
    })
    .then(r => r.json())
    .then(() => alert('Grade saved!'));
}
</script>
```

## Customizing LLM Behavior

### Adjust Question Difficulty

Edit `assessment_service.py`:

```python
# For harder questions
prompt += "\nGenerate CHALLENGING questions that test deep understanding."

# For easier questions
prompt += "\nGenerate INTRODUCTORY questions covering fundamental concepts."
```

### Adjust Grading Strictness

```python
# Strict grading
prompt += "\nUse high standards. Only award full points for excellent responses."

# Lenient grading  
prompt += "\nGive credit for partial understanding. Reward effort."
```

### Custom Rubrics

```python
# In SAQ prompt
rubric = {
    "technical_accuracy": "Code runs and logic is correct",
    "efficiency": "Solution is optimal or near-optimal",
    "documentation": "Clear comments explaining approach",
    "edge_cases": "Handles edge cases properly"
}

prompt += f"\nUse this rubric: {json.dumps(rubric, indent=2)}"
```

## Troubleshooting

### "GROQ_API_KEY not found"
- Add to `.env`: `GROQ_API_KEY=sk_...`
- Restart Flask app
- Verify key is valid at https://console.groq.com

### LLM grading fails, falls back to template
- Check API rate limits (Groq dashboard)
- Internet connection
- API key is valid
- No impact on system - instructor still grades manually

### Questions seem too easy/hard
- Adjust the prompt in `_generate_quiz_questions()`
- Add examples in prompt of difficulty level
- Test with sample questions first

### Grading confidence is low (<0.75)
- Review those responses manually
- Clarify rubric in grading prompt
- Add examples of good/poor responses to prompt

## Performance Impact

- **Course creation**: +10-15 seconds for question generation
- **Assessment display**: No change (<1ms)
- **Grading**: +10-20 seconds per essay (on-demand, not blocking)

Negligible impact on overall system performance.

## FAQ

**Q: Will using LLM cost money?**
A: Yes, but minimal (~$0.01-0.05 per course). Verify costs in Groq dashboard.

**Q: Can I disable LLM?**
A: Yes - methods fall back to template questions if LLM fails or is disabled.

**Q: Can I use different LLM?**
A: Yes - edit llm_client in assessment_service.py to use different provider.

**Q: Is grading always accurate?**
A: High confidence (>0.85) but should always review critical grades.

**Q: Can I customize prompts?**
A: Yes - edit the prompt strings in the _generate_* and llm_grade_* methods.

**Q: What if API rate limits hit?**
A: System falls back to manual grading. No data loss.
