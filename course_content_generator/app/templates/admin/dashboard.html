How the matrix is measured

Generation Time — Automatic wall-clock timing of LLM calls (course / notes / quiz). Manual ❌.

Completeness — Schema keys, module/lesson density, outcomes, resources. Manual expert /5 optional.

Relevance — Term alignment of course content with learner preferences/domain. Manual expert /5 optional.

Hallucination Rate — Optional heuristics (placeholders, thin text, weak URLs). Manual fact-check optional.

Usability (SUS) — Users complete the 10-item SUS survey; score 0–100 is computed automatically.

Learning Gain — Later vs earlier lesson quiz averages per learner-course path. Manual expert /5 optional.
